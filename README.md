# PulseCheck

A lightweight network and service monitoring tool built with Python.

## Overview

PulseCheck is a learning project focused on network monitoring, service availability, and performance analysis.

The goal is to build a tool that can monitor remote hosts and services, measure response times, and keep track of monitoring results.

## Planned Features

- Host availability monitoring
- Network latency measurement
- DNS resolution checks
- HTTP service status checks
- TCP port availability checks
- Monitoring history and statistics

## Technologies

- Python
- Git and GitHub
